# 工具与路径

本 Skill 提供素材制作流程，不附带图片模型、视频模型、转写服务、字体、人物照片或素材库。文本能力可以完成规划；成品需要当前环境确实能调用相应工具。

| 输入或输出 | 需要的能力 | 缺少时的处理 |
| --- | --- | --- |
| 已给定稿、SRT、VTT | 文件读取与文本处理 | 请用户提供可读取内容；不伪造已转写结果 |
| 只有录制视频 | 可核对的转写工具或配套字幕 | 先取得转写；不能仅凭文件名拆稿 |
| 原页证据 | 对应 PDF、Word、PPT 的读取和渲染工具 | 缺原件则请求材料，不用生成图片冒充原页 |
| 新场景、人物封面 | 可用图片生成/编辑工具，例如环境内的 imagegen | 说明未完成部分；只有用户要方案时才以提示词交付 |
| 精确公式、表格、数据图 | 可靠的排版、绘图和数值检查 | 不让生成模型猜数字或仿造规范页 |
| 无声 MP4 动画 | 可导出实际变化的动画工具，以及 FFmpeg 或同类编码、探测能力 | 可以复用已有工具，不要求特定服务；缺导出能力则不声称已交付 MP4 |

使用工具前核对当前环境的实际入口和能力；遵循该工具的文件读取、编辑与导出要求。不因本 Skill 写了某个工具名称就声称它已安装、已付费或支持某型号。

所有业务路径来自本次用户或本机已确认的配置。生成文件复制到指定交付目录；原件、历史版本和人工修改保留。素材库索引、人物参考与剪辑技能均为按需资源，不是安装本技能的前置条件。
