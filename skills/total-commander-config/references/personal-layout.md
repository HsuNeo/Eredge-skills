# 个人布局模板

此文件是公开示例，不包含发布者的真实业务目录。使用时先检查当前 TC 安装，再将用户明确确认的布局记录到本机已安装 Skill 的这个文件中；升级前保留本机修改。

| 用途 | 示例约定 |
| --- | --- |
| TC 根目录 | 用户指定或从当前进程、快捷方式确认 |
| 主工具栏 | 以实际配置为准，常见为根目录 Default.bar |
| 标签文件 | Tab\*.tab |
| 自定义菜单 | Bar\xpl\*.bar |
| 自定义图标 | PIC\*.ico |
| 原文件备份 | Backups\<时间-任务>\ |

TC 内部文件使用 `%Commander_path%` 引用；工作文档、课程、项目和源码目录保持各自真实路径。

可记录的内容：

- 需要保留的菜单名称，以及对应 BAR 文件。
- 最适合复制的标签模板，及其当前图标引用。
- 用户确认过的项目目录迁移关系。
- 书稿、每日连载等长期入口的父目录，避免绑定某一日期的子目录。

不要把示例目录当成已存在目录，不在公开仓库提交自己的真实配置、业务资料、账户信息或 TC 授权文件。
