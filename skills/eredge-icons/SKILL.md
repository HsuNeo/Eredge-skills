# 易睿捷业务图标

在当前开发任务中，先确定用户要改的页面、控件和业务含义。项目已有图标库时，从本地图册或现有样式中查找相应类名。例如，“定额查询”菜单与行内按钮可以共用定额轮廓，各自按所在控件选择配色。

## 在页面使用已有图标

图标资源由使用方提供。项目已引入 `@eredge/icons`、`eredge-icons.css` 或 `eredge-icons.wxss` 时，直接复用。只有技能说明时，可先确定资源规格，再请用户提供项目使用的样式文件、图册或离线图标包，以便核实可用类名。

- 在**原生微信小程序**中，将成品 WXSS 放入小程序，在 `app.wxss` 中引入一次。启用样式隔离的自定义组件在自己的 WXSS 中引入同一文件。普通图标用 `IEredge-<语义 ID>`，菜单预设配色用图册里已有的 `IEredge-menu-…` 类名，保留前缀大小写。
- 对于**原生底部页签**，将随包提供的普通态、选中态 PNG 放入小程序资源目录，在对应页签的 `iconPath`、`selectedIconPath` 中分别填写图片路径。
- 对于**已接入的网页或 WebView**，在公共样式入口引入成品 CSS。在行内按钮中可用 `IEredge-quota` 继承文字颜色，用 `font-size` 调整大小。保留原有按钮、点击区域和可访问名称。

例如，样式文件位于小程序的 `styles/eredge-icons.wxss` 时，在 `app.wxss` 加入 `@import "./styles/eredge-icons.wxss";`。下面两行放在已有的“定额查询”菜单控件内，点击事件仍由原控件处理。

```xml
<!-- 图标只作装饰，菜单名称由旁边的文字提供。 -->
<text class="IEredge-menu-quota-query" aria-hidden="true"></text>
<text>定额查询</text>
```

## 补绘与验收

1. 按业务对象、动作和同义词搜索图册。已有合适轮廓时，优先复用。仅需菜单配色时，在共享菜单映射中引用该底图。
2. 确实缺少语义时，在持有的图标源码项目中修改 SVG 主图集。使用稳定的小写英文 ID，单词间用连字符，填写便于搜索的中文名称。沿用 24 × 24 母版、2 单位线宽、圆端圆角，保留已发布的 ID 和字形码位。采用第三方路径时，核对对应版本的许可，记录来源和修改内容，并随成品保留所需的版权和许可声明。
3. 按源码项目的维护说明重建图标包，同步单图和编码索引，运行该项目提供的生成结果检查。使用方只有成品样式时，新增共享图形需由持有主图集和导出工具的人完成。
4. 在目标页面按实际尺寸检查轮廓是否清楚。菜单、工具栏、移动入口和大按钮的参考尺寸分别为 16、20、24 和 32。按宿主支持的主题查看对比度，切换页签核对两种状态。纯图标按钮要有可访问名称。

首次试用以用户选定的小程序页面为范围。后续若指定其他宿主，Office/WPS Ribbon 选用透明 PNG，WPF 选用几何资源。收到试用反馈时，先确定修改的是当前页面还是共享图形，再更新相应文件。

持有完整源码的维护者可从源码根目录打开 `Shared/Icons/index.html` 选图。主图集是 `Shared/Icons/eredge-icons.svg`，菜单配色在同目录的 `menu-variants.json`。使用项目已配置的构建环境，在源码根目录执行以下命令。

```powershell
# 从主图集生成样式、字体和页签图片，再同步单图与编码索引。
py -X utf8 DevTools/build-eredge-icon-package.py
py -X utf8 DevTools/sync-eredge-icon-docs.py

# 核对共享包和文档产物是否与源文件一致。
py -X utf8 DevTools/build-eredge-icon-package.py --check
py -X utf8 DevTools/sync-eredge-icon-docs.py --check
```
