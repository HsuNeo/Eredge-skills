# 桥梁项目续作例

本页是桥梁工程续作示例，说明如何记录和核对历次约定。示例工程、参考片、配音和声音档案不随技能分发；新工程以自己的图纸、参考片、品牌、声音与交付要求为准。

## 从哪里接手

原项目位于 `E:\AI-Work\projects\桥梁施工动画`。先打开项目根目录的《项目说明.md》，再读 `output` 的版本说明。脚本、工程所在目录按对应版本的实际引用定位。

- V2 记录参考视频、27 个分镜及脚本中的分镜编号。预览先查工序和动作，再看材质。原片品牌替换为“易造价在手，下班就能走”，片头或片尾和合适的画面空位自然摆放，避免遮住构件。逐镜清理原片单位名、名称、Logo。片尾品牌字是场景元素；交付无讲解字幕版本时仍保留。
- V3 的“修改对照与时间轴”CSV、同名成片 SRT、逐段配音 WAV 和逐条原声 ZIP 能追到每一条字幕的原文、改文、帧区间、朗读字数、配音倍率和来源。本例使用经作者授权的本地声音档案，需要重新合成时先核对当前环境的声音档案和可用工具。只改画面或加字幕时复用已核验的声音。
- V4 的成片、Blender 工程、精修生成脚本和正式渲染脚本放在 `output`。全片原生 2560×1440、30 fps、5,249 帧，时长 02:54.967。V4 不应被当成所有新动画的固定规格。用文件名区分“正式成片”（有配音、外挂同名 SRT）和“含字幕成片”（有配音、内封默认开启的中文字幕轨）。

## 哪些画面尤其要看

- 桩基剖面应能看清钻进土层、钢筋笼吊放、导管下口和孔底混凝土顶升。桩头处理分拍呈现环切、分离、顶裂、垂直吊离。避免用停帧代替连续动作。
- 模板看合拢、浇筑和拆除的先后，透明度可用来展示模板内混凝土的变化；近景看法兰、螺栓、双螺母及接缝。双机抬吊看两台起重机、吊索、同一片梁及落梁位置的连贯关系。
- 本桥面防水层按用户指定用低饱和灰绿色。施工中与已完成状态共用材质，抽看前后两镜，确保能区别浅灰混凝土基层、灰绿涂层和深灰沥青。无实物色卡时标为示意调色。其他项目从各自的材料和参考取色。
- 本例发布素材选双机抬吊镜头作参考，标题“桥梁施工动画”，副题“从桩基到桥面”。横竖封面重新构图；简介交代模型、场景、动画和按字幕配音的制作顺序。
